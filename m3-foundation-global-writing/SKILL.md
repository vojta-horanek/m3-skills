# Global writing

## Scope

Source: [Global writing overview](https://m3.material.io/foundations/content-design/global-writing/overview).

Write inclusively across cultures and make localization easier.
This guidance applies to American English that will be localized and can improve writing for other audiences.

## Words and translator context

Source: [Global word choice](https://m3.material.io/foundations/content-design/global-writing/word-choice).

- Use global examples instead of unexplained local places, holidays, or companies.
- When a local reference is necessary, explain it in the message description so translators can substitute an appropriate reference.
- Provide context for locations, names, currencies, temperatures, date formats, and service providers.
- Use short, simple sentences. Use bullets or sections with headings for longer content.
- Allow for translated text averaging about 1.5 times the English length.
- Spell out abbreviations where possible. Common time abbreviations are acceptable.
- Explain any necessary abbreviation in its message description.
- Replace an ambiguous pronoun with its noun, or identify the noun in the message description.
- Do not start with “this” or “that” unless the noun immediately follows.
- Avoid idioms and colloquial phrases. Explain their purpose and context if they are used.
- Avoid polite filler, especially in errors. “Please” can suit a request that inconveniences the user.
- Reduce technical jargon. Use simple descriptions that translate clearly.
- Avoid different meanings of an ambiguous word within the same string or body of text.
- Explain ambiguous meanings in the message description.

## Verify localization readiness

Check local references, pronoun antecedents, abbreviations, ambiguous terms, and available translator context.
Check that longer translations can fit without losing information.
