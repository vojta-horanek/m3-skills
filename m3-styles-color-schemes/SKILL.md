# Choose a color scheme

Use only the directions from the supplied Material 3 sources. Do not invent missing values or behavior.

Read the [source manifest](../m3-styles-sources.json) for source coverage.
Open the supplied source pages for tables, diagrams, and token modules.

Source: [Choosing a scheme: Tab 1](https://m3.material.io/styles/color/choosing-a-scheme).

## Choose the scheme

- Use a scheme to define colors, roles, and relationships across light and dark themes.
- Choose static baseline when dynamic color is not ready or when migrating an M2 product.
- Consider static baseline for iOS or enterprise products without a need for personalized color.
- Use dynamic color for wallpaper personalization, content-based color, or user-controlled contrast.
- Do not expect identical colors across devices with dynamic color.
- A dynamic scheme can include static colors as product needs develop.

## Design and verify

- Start dynamic designs with baseline colors to establish correct role mappings.
- Use Material Theme Builder to preview a range of source colors.
- Adjust designs based on these previews while preserving intended role relationships.
- Distinguish static baseline accessibility from dynamic support for user-controlled contrast.
