# Button selection

Use only the directions supported by the linked Material 3 sources. Do not infer missing measurements or behavior.

Read [source details](references/source-map.md) for source coverage, measurement diagrams, and token-table locations.

Source: [All buttons](https://m3.material.io/components/all-buttons).

Choose among buttons, toggle buttons, icon buttons, split buttons, button groups, FABs, extended FABs, and FAB menus.

## Choose and place buttons

- Give each screen one prominent button for its primary action.
- Use FABs or extended FABs for the main action. Use a FAB menu for related options.
- Use filled buttons for final actions or actions that unblock a flow.
- Use split buttons for key actions with related options.
- Use standard button groups for multiple key actions.
- Use tonal buttons for supporting actions that need moderate emphasis.
- Use elevated buttons only when a patterned background requires visual separation.
- Use outlined buttons for secondary actions or an opportunity to leave a flow.
- Use connected button groups for related options that change visible content.
- Use text buttons for optional actions.
- Use icon buttons for compact, supplementary actions.
- Combine color styles to show each action's importance.
- Place buttons side by side when space permits.
