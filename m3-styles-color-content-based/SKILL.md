# Content-based dynamic color

Use only the directions from the supplied Material 3 sources. Do not invent missing values or behavior.

Read [source details](references/source-map.md) for section links, source tables, diagrams, and token modules.

Source: [Dynamic: Content-based source](https://m3.material.io/styles/color/dynamic/content-based-source).

## Apply content-based color

- Use in-app content, such as album artwork, logos, or video previews, as the source.
- Use image quantization to select the source color and generate role tones.
- Apply content color where it supports brand identity and personalization.
- Use publication colors to distinguish brands and help navigation when appropriate.
- Scope the scheme to a set of components or a particular screen.
- Use the color tokens and roles built into Material Theme Builder.
- Confirm the preferred scheme before generating colors from an image.

## Verify

Check the scheme against its source content and intended screen area.
Use the source page's development link for content-based dynamic color integration.
