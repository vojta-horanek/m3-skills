# Assistive technology

Source: [Assistive technology](https://m3.material.io/foundations/overview/assistive-technology).

## Input and output needs

- Account for keyboards, screen readers, braille displays, tracking input, magnifiers, and voice input.
- Support directional controllers such as a keyboard, D-pad, or trackball. These can move linearly between selections.
- Account for screen readers that speak text or use a braille display.
- Include visible paragraphs and button text in the text-based experience.
- Label hidden content, including meaningful icons and headings, to improve the screen reader experience.
- Account for switch input that scans and highlights items in turn until the user selects one.
- Distinguish an icon's visible size from its larger interactive target.

## Verify the experience

- Check linear navigation between selections with a directional controller.
- Check that a screen reader identifies visible and relevant hidden content.
- Check that switch users can reach and select items through scanning.
