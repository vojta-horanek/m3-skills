# Dynamic color sources

Use only the directions from the supplied Material 3 sources. Do not invent missing values or behavior.

Read the [source manifest](../m3-styles-sources.json) for source coverage.
Open the supplied source pages for tables, diagrams, and token modules.

Source: [Dynamic: Choosing a source](https://m3.material.io/styles/color/dynamic).

## Choose the source

- Choose wallpaper-based color when user preference and personalization are the main need.
- Choose content-based color when content is central and color supports features such as media players.
- Use content-based color mainly in contained areas adjacent to its source image.
- Account for the customization needed by content-based color.
- Use multiple sources when product needs meet both sets of criteria.
- Start combined schemes with user-generated color before customization.

## Verify

Check whether the source supports the product's content or user preference needs.
For combined schemes, follow the source's advanced color application guidance.
