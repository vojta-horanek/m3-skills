# Material glossary reference

Source: [Glossary](https://m3.material.io/foundations/glossary).

## Color and styling

| Term | Meaning |
| --- | --- |
| Baseline scheme | Default selected tones for light and dark color schemes |
| Dynamic color | User-generated schemes accepted as inputs to changeable app color roles |
| Extended color | Additional color for custom roles, such as brand or conventional semantic meaning |
| Key color | A hue-and-chroma transformation of the source color, forming a tonal palette's basis |
| Scheme | Mapping of color roles to tones from tonal palettes |
| Source color | Initiating color from which five key colors derive |
| Tonal palette | A 13-tone range used to map tones to color roles |
| Tone | Degree of lightness within colors of the same hue and chroma |
| User-generated scheme | Colors derived from wallpaper or Android preset choices |
| Contrast | For accessibility, difference in tone. Tone differences of 40 and 50 guarantee at least 3:1 and 4.5:1 respectively. |
| HCT | Hue, chroma, tone. Uses CAM16 hue and chroma, with CIELAB L* represented as tone. |
| Customization | Changes reflecting an app, manufacturer, or user's preferences or brand |
| Dark theme | Low-light UI with mostly dark surfaces |
| Material Theming | Systematic customization for a product brand |
| Style | Properties defining an aspect of appearance, such as color, type, or shape |
| Theme | Combined styles applied globally to adjust component appearance consistently |

## System, layout, and documentation

| Term | Meaning |
| --- | --- |
| Adaptive design | Interface changes based on known user, device, or environmental conditions |
| Condition | Signal determining when and how layout or component adaptation occurs |
| Design attribute | Style aspect to which a token or value applies |
| Design guidelines | Written and illustrated explanations of usage and behavior |
| Design specs | Annotated designs and documents defining coded values and capabilities |
| Design System Package | Adobe's open folder format for sharing design system information across tools |
| Design token | Named, reusable design decision replacing a static style value |
| Token context | Conditions where tokens refer to non-default values |
| Token role | Short system-token name describing purpose |
| Reference token | Available tokenized value |
| System token | A system choice or role for color, type, elevation, shape, or another style |
| Component token | Design attribute of a component element |
| Token value | Information defining a design attribute |
| Element | Component part to which a token or value applies |
| Role | Short purpose-based token name, also called a slot |
| Mode | Binary system setting, such as focus mode or airplane mode |
| Orbiter | Floating UI controlling content in spatial panels |
| Pane | Content-and-action grouping that adapts to available screen space |
| Spatial | UI placement in extended-reality space |
| XR | Extended reality, including virtual reality and passthrough with the physical environment |
| Material Design | Adaptable guidelines, components, and tools for interface design |
| Material Components | Open-source UI elements for implementing Material across platforms |
| Libraries | Developer implementations of Material components |
| M1 | First Material generation, launched in 2014 |
| M2 | Second generation, launched in 2018, introducing Material Theming |
| M3 | Third generation, launched in 2021, including Material You features |
| Material You | Personal and expressive visual style and features within M3 |

## Components

| Term | Meaning |
| --- | --- |
| App bar | Top-of-screen information and actions |
| Banner | Prominent message with optional related actions |
| Button | Action initiation |
| Bottom sheet | Supplementary content anchored to the bottom |
| Card | Content and actions about one subject |
| Checkbox | One or more selections or an option toggled on/off |
| Chip | Input, selection, filtering, or actions in a compact shared area |
| Data table | Data arranged in rows and columns |
| Date picker | Date or date-range selection |
| Dialog | Important prompt, information, or task in a flow |
| Divider | Thin line grouping list or layout content |
| Extended FAB | Primary-action control with space for a label and larger target |
| FAB | Most important screen action placed within reach |
| Image list | Organized image grid |
| List | Continuous vertical index of text or images |
| Menu | Choices on a temporary surface |
| Navigation bar | Persistent switching among primary destinations |
| Navigation drawer | Ergonomic access to app destinations |
| Navigation rail | Primary destinations on tablet and desktop layouts |
| Progress indicator | Unspecified wait or process length |
| Radio button | One selection from a set |
| Side sheet | Supplementary content anchored to a side edge |
| Slider | Selection from a range |
| Snackbar | Brief process message near the bottom |
| Switch | On/off state for one item |
| Tab | Organization across screens, data sets, or interactions |
| Text field | Text entry and editing |
| Time picker | Specific time selection |
| Toolbar | Navigation and key actions, described in the glossary at the bottom of mobile screens |
| Tooltip | Informative text on hover, focus, or tap |
