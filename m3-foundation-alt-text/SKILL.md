# Alt text and adjacent content

## Meaning and context

Source: [Alt text](https://m3.material.io/foundations/content-design/alt-text).

- Write alt text for informative images. Describe the meaning and context users need when they cannot see the image.
- Do not use a generated filename as alt text.
- If removing an image loses no information, treat it as decorative. On the web, a null alt attribute hides it.
- Focus on the image's purpose in its current context, rather than irrelevant details.
- Do not begin with “image of” or “picture of.” Screen readers announce the image role.
- Use adjacent text, headings, and captions to determine emphasis and terminology.
- Keep terminology consistent with the caption. Do not duplicate the caption in alt text.
- Adapt alt text when the same image appears in a different context.
- Write captions that help sighted and screen reader users understand meaning, rather than repeating visible details.
- Name an image type only when useful, such as a chart, map, graph, screenshot, headshot, or diagram.

## Source length difference

The dedicated alt-text page recommends 140 characters and cautions against longer text.
[Writing best practices](https://m3.material.io/foundations/writing/best-practices) describes alt text as up to 125 characters.
These sources give different limits. Keep each limit attributed to its source rather than presenting one agreed Material limit.

The writing page also directs authors to put essential text embedded in an image into its alt text.
Use surrounding text and captions to explain how an image relates to the content.

## Charts and graphs

- Describe the chart's purpose and the information needed to use it.
- Link to underlying data when available.
- For an editorial chart, describe its key takeaway and the main metrics that support it.
- Use existing body text, labels, and chart text to establish that meaning.
- For an analysis chart with one or two clear takeaways, include them.
- For analysis with many possible takeaways, describe the structure and opportunities for exploration without imposing a misleading summary.
- Do not list every data point as a substitute for meaning.
- Consider interactive charts for complex analysis. Tooltips can expose details for individual points.

## Motion

- Give informative animations and GIFs alt text when their information is not available elsewhere on screen.
- Summarize the important action, rather than every motion detail.
- Long-form video uses video description to narrate visual content instead of alt text.

## Review

Check meaning, context, caption duplication, decorative treatment, chart purpose, and the applicable source length guidance.
