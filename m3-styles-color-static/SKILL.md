# Static baseline color

Use only the directions from the supplied Material 3 sources. Do not invent missing values or behavior.

Read [source details](references/source-map.md) for section links, source tables, diagrams, and token modules.

Source: [Static: Baseline](https://m3.material.io/styles/color/static).

## Apply baseline colors

- Use baseline accessible color pairings in both light and dark themes.
- In new Figma files, enable the M3 Design Kit in Assets.
- Compose screens with kit components.
- Apply M3 baseline color roles to custom elements according to their intended use.
- Select the color property's Style icon and search for M3 roles.

## Update an existing file

1. Open Material Theme Builder from the Figma Actions menu.
2. Enable Generate State Layers in Settings.
3. Select Baseline in Current Theme.
4. Select the frames or components.
5. Select Swap to update M3 Design Kit component colors.
6. Inspect Selection colors for remaining hex values or non-M3 styles.
7. Replace each remaining color with the baseline role matching its use.

## Verify

Check all custom elements and interaction state layers.
Check both themes with intended role pairs.
Use the source token module for baseline values and palette values.
